# The Hungry Canvas 🍽️

A responsive restaurant menu website built using HTML, CSS, and JavaScript. The website showcases delicious food items in an attractive and user-friendly layout.

## 📌 About the Project

The Hungry Canvas is a restaurant website designed to provide visitors with information about the restaurant, explore its menu, learn about its story, and find contact information.

## ✨ Features

- Attractive restaurant navigation header
- Hero section with a welcome message and food image
- Food menu with images, descriptions, and prices
- About section introducing the restaurant
- Contact section with restaurant information
- Responsive layout for desktop and mobile devices
- Interactive menu category filters (planned)
- Smooth hover effects and navigation

## 🛠️ Technologies Used

- HTML5 — website structure
- CSS3 — styling, layouts, and responsive design
- JavaScript — interactive features (as implemented)

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Explore the restaurant website.
